# Instagram Platform Rules & Carousel Specs

## Carousel Post Specs
- **Format:** 4:5 (1080×1350px) — simuliert als 480×600px im HTML-Artifact
- **Slides:** min. 2, max. 10 pro Carousel
- **Empfohlen:** 7–10 Slides (Hook → Wunde → Warum → Wert-Kern → Aha → Summary → CTA)
- **Dateiformat:** JPEG oder PNG, max. 8 MB pro Bild
- **Video in Carousel:** möglich, aber für diesen Skill: nur statische Slides

## Caption-Regeln
- Max. 2.200 Zeichen
- Hashtags: 5–8 (optimal), max. 30 erlaubt
- Erste Zeile = Hook (entscheidet über "mehr lesen")
- Zeilenumbrüche mit Leerzeilen trennen
- Emojis sparsam, nur wenn zur Marke passend

## Veröffentlichung via MCP
- `create_instagram` erstellt nur einen Entwurf (Draft)
- Für jedes Bild: öffentliche URL erforderlich (`media_url`)
- Bilder müssen vor dem MCP-Call hochgeladen und per URL erreichbar sein
- Veröffentlichung erfolgt nach Nutzerbestätigung in der UI
