# CV Schema Reference

Use this reference when Roger needs a structured master CV, an audit table, or a canonical source-of-truth model.

## Master CV Fields

| Field | Required | Notes |
|---|---|---|
| full_name | Yes | Roger Basler de Roca. |
| headline | Yes | Current strategic positioning. |
| location | No | Only include if Roger wants location visible. |
| contact_links | Yes | Website, LinkedIn, books, media kit, booking link if available. |
| executive_summary | Yes | 4 to 8 lines, decision-relevant. |
| roles | Yes | Role, organisation, start date, end date, current flag, summary, proof. |
| projects | No | Use when a project has strategic relevance or measurable impact. |
| speaking | No | Event, title/topic, year, location, link, proof. |
| publications | No | Title, type, publisher/platform, year, link, proof. |
| education | Yes | Degree/programme, institution, status, year or period. |
| research | No | PhD topic, research interests, papers, teaching if applicable. |
| awards | No | Award/ranking, issuer, year, proof. |
| media | No | Interview, podcast, article, platform, date, link. |
| skills | Yes | Evidence-based skills grouped by domain. |
| languages | No | Only if useful for the target CV. |
| version | Yes | Date, editor, change summary. |

## Change Types

| Type | Definition | Approval Needed |
|---|---|---|
| factual_addition | New fact, role, talk, publication, award, education, client, metric. | Always. |
| factual_correction | Date, title, spelling, chronology, link, status. | Always. |
| wording_improvement | Better phrasing without changing facts. | Yes before applying. |
| formatting | Layout, headings, section order. | Yes before overwriting/exporting. |
| deletion | Removing old or weak material. | Always. |

## Evidence Record

For every proposed change, capture:

| Field | Description |
|---|---|
| source_type | User input, document, official website, Notion, Google Drive, LinkedIn export, media source. |
| source_reference | File path, URL, page title, or note. |
| date_accessed | YYYY-MM-DD. |
| confidence | High, Medium, or Low. |
| open_question | What Roger must confirm before use. |

## Versioning Convention

Use this pattern for files when Roger has not specified another convention:

`Roger_Basler_de_Roca_CV_[variant]_[YYYY-MM-DD]_v[major.minor].[ext]`

Examples:

| File | Use |
|---|---|
| Roger_Basler_de_Roca_CV_Master_2026-05-22_v1.0.md | Master CV draft. |
| Roger_Basler_de_Roca_Bio_Short_2026-05-22_v1.0.md | Short bio. |
| Roger_Basler_de_Roca_Speaker_Profile_2026-05-22_v1.0.md | Speaker profile. |
