# Motivation Letter Workflow

Use this reference when Roger provides a job advertisement, role description, mandate brief, grant call, board opening, fellowship call, university position, or consulting opportunity and asks for a motivation letter.

## Input Requirements

Before drafting, identify the available inputs and ask only for what is genuinely missing.

| Input | Required | Purpose |
|---|---|---|
| Job advertisement or role description | Yes | Extract requirements, language, priorities, and hidden evaluation criteria. |
| Target organisation | Yes | Understand context, tone, mission, and strategic fit. |
| Roger's CV or profile material | Yes | Ground claims in evidence. |
| Desired language | No | Default to the advertisement language if not specified. |
| Submission format | No | Email, formal letter, online text box, PDF letter, or short note. |
| Contact person | No | Use only if provided or clearly visible in the ad. |
| Salary, availability, relocation | No | Mention only if Roger explicitly approves. |

## Advertisement Analysis

Extract the explicit and implicit decision criteria. Do not merely mirror the advertisement. The task is to translate Roger's profile into the employer's problem space.

| Analysis Layer | What To Extract | Why It Matters |
|---|---|---|
| Role purpose | What the organisation needs solved | Opens the letter with relevance, not biography. |
| Must-have criteria | Non-negotiable skills, experience, qualifications | Prevents elegant but irrelevant prose. |
| Nice-to-have criteria | Secondary preferences and cultural signals | Creates differentiating evidence. |
| Hidden pressure | Growth, transformation, regulation, AI, education, market change | Shows strategic understanding. |
| Language markers | Words repeatedly used in the ad | Aligns tone without parroting. |
| Risk signals | Vague scope, overpacked role, unclear seniority | Avoids overpromising. |

## Matching Logic

Create a fit matrix before drafting. Every strong claim in the letter should trace back to either the advertisement or Roger's verified profile.

| Requirement From Ad | Roger Evidence | Letter Angle | Confidence |
|---|---|---|---|
| [Requirement] | [Verified CV/profile evidence] | [How to frame it] | [High/Medium/Low] |

Use low-confidence evidence only as a question for Roger, not as a finished claim.

## Letter Structure

Use this structure unless the target format clearly requires something else.

| Section | Function | Writing Guidance |
|---|---|---|
| Opening | State why this role matters and what problem Roger can help solve | Start with the organisation's challenge, not with "I hereby apply". |
| Strategic fit | Connect Roger's experience to the role's core requirements | Use 2 to 3 precise evidence points. |
| Differentiation | Explain what makes Roger unusually relevant | Emphasise digital business, AI, education, algorithms, strategy, or leadership where relevant. |
| Contribution | Show concrete value in the first 6 to 12 months | Be specific but do not invent a plan. |
| Closing | Invite conversation and confirm motivation | Confident, concise, not needy. |

## Style Rules

Write in a tone that is sovereign, warm, precise, and adult. A strong motivation letter is not a motivational poster that escaped HR. Avoid generic phrases such as "I am a team player", "dynamic environment", "passionate about challenges", or "I perfectly match your requirements" unless the sentence earns its oxygen.

For German letters, use Swiss spelling and avoid ß. Use ä, ö, ü correctly. Avoid em dashes. Keep sentences controlled and clear. The letter should sound like Roger: strategic, reflective, practical, subtly sharp.

## Quality Bar

A strong draft must pass these checks:

| Check | Standard |
|---|---|
| Relevance | The first paragraph clearly reflects the target role and organisation. |
| Evidence | Main claims are grounded in Roger's CV or provided material. |
| Specificity | The letter contains role-specific reasoning, not generic flattery. |
| Tone | Confident but not arrogant, personal but not confessional. |
| Risk control | No invented facts, dates, titles, metrics, affiliations, or availability. |
| Decision value | The reader understands why Roger is worth a conversation. |

## Approval Rule

Before finalising, sending, uploading, or converting into a submission format, present the draft to Roger for review. If applying via email, portal, LinkedIn, Notion, Google Drive, or any external system, ask for explicit approval before every external action.
