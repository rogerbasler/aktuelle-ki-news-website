# Suno Music Creation Workflow

This skill provides the standard workflow for creating music with Suno AI, ensuring high-quality lyrics, proper formatting, and consistent visual identity.

## 1. Understanding the Vision

Before writing any lyrics or prompts, gather the following information:
- **Initial concept:** Theme, rough lyrics, or core idea.
- **Musical style:** Genres, instruments, cultural influences.
- **Emotional tone:** Hopeful, angry, melancholic, celebratory, etc.
- **Context:** Any relevant current events or cultural background.

## 2. Lyric Development

Follow a structured approach to lyric writing:
1. **First Draft:** Structure raw ideas into proper song format (Verses, Choruses, Bridges).
2. **Refinement:** Expand, shorten, or rewrite sections based on feedback.
3. **Bilingual Integration:** Seamlessly weave multiple languages together if requested (e.g., French-Arabic, English-Farsi).
4. **Emotional Arc:** Ensure the song has a journey, building from one emotional state to another.

## 3. Suno Optimization

Always create **two versions** of every song:

### A. Suno-Ready Version
- **Style Prompt:** Detailed description of genre, instruments, vocal style, and mood.
  - *Example:* "Epic orchestral hip-hop, cinematic strings, Moroccan fanfares, Nafir horns, heavy 808 rap beat..."
- **Lyrics with Tags:** Clean lyrics using ONLY Suno-recognized tags.
  - *Valid Tags:* `[Verse]`, `[Chorus]`, `[Pre-Chorus]`, `[Bridge]`, `[Outro]`, `[Intro]`, `[Instrumental Break]`, `[Guitar Solo]`, `[Beat Drop]`, `[Whispered]`, `[Rap]`, `[Spoken]`.
  - *Rule:* Do not use descriptive text inside brackets (e.g., `[sad verse]` is invalid).

### B. Clean Lyric Book Version
- No tags, just pure poetry.
- Formatted beautifully for reading, printing, or sharing.

## 4. Visual Identity

For each song, create:
- **Album/Single Cover Art:** Captures the mood and themes.
- **Style options:** Offer photographic/realistic, symbolic/artistic, or portrait-focused options.
- **Iterations:** Refine based on feedback (lighting, composition, grittiness, etc.).

## 5. Video Content (if requested)
- 9:16 vertical clips for social media.
- Keyframe-based generation for smooth transitions.
- Symbolic or narrative visuals that match the song's message.

## 6. Artist Development (if creating a persona)
- **Bio writing:** Background, influences, artistic vision.
- **Name suggestions:** Culturally authentic, memorable.
- **Album concepts:** Tracklist, themes, overall narrative arc.

## Key Principles
- **Iterative refinement:** Never stop at the first draft.
- **Cultural authenticity:** Research and respect cultural elements.
- **Suno-specific formatting:** Understand the difference between style prompts and lyric tags.
- **Emotional depth:** Songs should have a journey, not just words.
- **Visual coherence:** All artwork maintains a consistent aesthetic.
- **User vision first:** Adapt to feedback, do not impose ideas.
