# Key-Visual Prompt Patterns

Use these prompt patterns when creating image-based TED-style presentation slides. Keep prompts concrete, visual and scene-driven.

## Pattern 1: Black Stage Thesis

Use for opening theses and major shifts.

```text
Title: [CORE THESIS]
Key text: [OPTIONAL ONE-LINE CONTRAST]
Visual Elements: A cinematic black stage, one dramatic red spotlight, one object or metaphor illuminated in the centre, electric-blue data light, lime-green clarity accent, heavy negative space, photographic drama, no logo.
Layout Preference: Huge title on upper-left or centre-left, visual metaphor on centre-right, very little text.
Text Hierarchy: The core thesis must be readable from far away.
Continuity Note: Maintain black stage, red spotlight, electric-blue system light, lime accent sparks, graffiti-tech scratches.
```

## Pattern 2: Split World

Use when the message contains a contrast.

```text
Title: [CONTRAST STATEMENT]
Key text: [OPTIONAL SHORT TRANSFER]
Visual Elements: Split-screen cinematic scene. Left side shows [old/bad state] in red, chaos, distortion, smoke. Right side shows [new/good state] in electric blue and lime, clarity, structure, clean signals. A central prism, gate or rupture separates both worlds.
Layout Preference: One word on each side, title across top, strong diagonal split.
Text Hierarchy: Contrast words must be large and readable.
Continuity Note: Keep the same cinematic black stage, red/blue/lime accents and minimal typography.
```

## Pattern 3: System Gate

Use for algorithms, ATS, filters and decision systems.

```text
Title: [SYSTEM CLAIM]
Key text: [SHORT WARNING OR TRUTH]
Visual Elements: A huge red scanner or filter gate on a black stage. Inputs flow into the gate from left. Only clean lime-green signals pass through on the right. Electric-blue scan line cuts through the scene.
Layout Preference: Title on left, filter gate centre-right, output signal far right.
Text Hierarchy: System claim dominates. Keep all labels short.
Continuity Note: Maintain cinematic black, red gate, blue scan light, lime pass signal.
```

## Pattern 4: Human Versus System

Use when showing agency, self-marketing or interview preparation.

```text
Title: [HUMAN AGENCY CLAIM]
Key text: [ONE-LINE INSIGHT]
Visual Elements: Human silhouette in spotlight, system or AI structure opposite or behind the person, electric-blue analysis beams, red tension light, lime clarity rim light around the human.
Layout Preference: Human silhouette near centre, title large with negative space, system visual behind or opposite.
Text Hierarchy: The human agency claim must be the focal text.
Continuity Note: Do not make AI overpower the human; it should sharpen the human outline.
```

## Pattern 5: Mission Control Transfer

Use for action plans and next steps.

```text
Title: [ACTION COUNT OR SPRINT]
Key text: [SHORT OUTCOME]
Visual Elements: Mission-control wall with glowing output tiles, black stage, human silhouette observing the board, electric-blue tile frames, red urgency accents, lime completion signals.
Layout Preference: Title on left, visual board on right, 5 to 7 output words maximum.
Text Hierarchy: Title first, output words second, no explanations.
Continuity Note: Keep cinematic black stage and the same red/blue/lime system.
```
